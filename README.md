-	Developed a mobile application that enables customers to place orders by scanning dynamically generated QR codes for restaurant menus, streamlining the ordering process.
-	Implemented real-time order tracking and order history management features, enhancing the customer experience by allowing them to monitor their current orders and review past purchases.
-	Integrated a backend system for restaurants to create dynamic QR codes, track active orders, and maintain comprehensive order histories, improving operational efficiency.
